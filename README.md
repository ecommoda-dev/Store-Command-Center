# 🎯 مركز قيادة المتجر · Store Command Center

**لوحة المدير لمتجر EcomModa.** مش شاشة أرقام — شاشة **قرارات**: كل رقم جنبه
«ده معناه إيه» و«اعمل إيه دلوقتي»، ومرتّبة بالأثر بالجنيه مش بالنسبة المئوية.

| | |
|---|---|
| **الواجهة** | https://ecommoda-dev.github.io/Store-Command-Center/ |
| **الـ API** | Cloudflare Worker · `store-command-center-worker` |
| **الصلاحية** | قراءة فقط — الأداة **مش** بتكتب أي حاجة على شوبيفاي |
| **الدخول** | Universal D1 Auth (اسم + PIN) |

## المبادئ اللي الأداة اتبنت عليها

1. **كل رقم جنبه قرار.** رقم من غير «اعمل إيه» بيتشال، مش بيتعرض.
2. **الرؤى مرتّبة بالفلوس.** ٥٠% على ٢,٠٠٠ جنيه بتيجي بعد ٣% على ٤٠٠,٠٠٠.
3. **«مش عارفين» ≠ صفر.** ناقص تكلفة؟ الهامش بيظهر «—». مفيش عيّنة؟ بيقول كده.
4. **الحدود معلنة.** اللي الأداة مش شايفاه مكتوب في الشاشة نفسها، مش مخبّى في ملف.
5. **كناري الأعطال.** أي حالة جديدة أو متعارضة بتقع في مربع «خارج التصنيف» الظاهر
   بدل ما تتبلع في مربع تاني وتطلّع رقم غلط بصمت.
6. **حالة الخطأ مبتعرضش أرقام.** لا قديمة ولا أصفار — لأن شاشة فيها أرقام تحت
   بانر أحمر شكلها زي الشاشة السليمة.

## البنية

```
index.js                  الـ Worker — كل الحساب هنا، الواجهة بتعرض بس
index.html                الواجهة (ملف واحد، RTL، بدون build step)
wrangler.toml             إعدادات الـ Worker والـ bindings
docs/
  DATA-CONTRACT.md        📌 المرجع الأول — كل رقم منين وبأي معادلة وبأي حدود
  DEPLOY.md               النشر خطوة بخطوة + الفخاخ المعروفة
  IMPROVEMENTS.md         المقترحات والتحسينات (مرتّبة بالأثر)
test/
  harness.mjs             76 اختبار على لقطة حقيقية من المتجر
  browser-test.mjs        75 فحص في متصفح حقيقي (Playwright)
  make-payload.mjs        بيبني حمولة الاختبار من نفس اللقطة
CLAUDE.md                 دليل الشغل على الريبو ده لأي جلسة جاية
```

**مصادر البيانات ثلاثة:**

| المصدر | بيدّي إيه | تكلفته |
|---|---|---|
| أوردرات الفترة (شوبيفاي) | كل الفلوس والتشغيل والجغرافيا | الأغلى — بيتكاش |
| الكتالوج (شوبيفاي) | التكلفة · البراند · الفئة · الكوليكشن · المخزون | **مستقل عن الفترة** — كاش ٦ ساعات |
| سجل D1 | التغليف · التحصيل · الجرد · المزامنة · السجل | تكلفة صفر على شوبيفاي |

الفصل ده مقصود: التكلفة والبراند بييجوا من الكتالوج بالـ SKU بدل ما يتجابوا
داخل كل سطر في كل أوردر — نفس الرقم بجزء بسيط من التكلفة.

## التشغيل والاختبار محليًا

```bash
node test/harness.mjs        # الأرقام صح؟ (بيانات حقيقية، بيطبع الهوية المحاسبية)
node test/make-payload.mjs   # بيبني test/payload.json للاختبار التالي
node test/browser-test.mjs   # الواجهة بترسم؟ (--shots للقطات شاشة)
```

> `test/payload.json` · `test/shots/` · `data/` كلهم في `.gitignore`.
> **الريبو عام** — ممنوع يدخله أي بيانات عملاء حقيقية.
